# ADR 0001: RDF/OWL como semântica e SHACL como contrato operacional

Status: aceito em 2026-08-08.

RDF fornece identidade global e composição; RDFS/OWL expressam hierarquia e semântica aberta. Essa abertura não garante completude de registros operacionais. SHACL é usado na fronteira de escrita para cardinalidade, tipo, lista permitida e regras de segurança. JSON Schema protege contratos de API. Nenhuma dessas camadas substitui a outra.
